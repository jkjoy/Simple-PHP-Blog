# Clay 黏土主题

一个为 Simple PHP Blog 设计的黏土拟态主题，视觉语言受 [clay.css](https://github.com/codeAdrian/clay.css) 启发。

主题使用 clay.css 的核心思路：外投影建立悬浮层级，两组内投影塑造柔软的立体表面。为保证博客阅读体验，黏土效果仅用于导航、卡片、按钮和表单控件，正文保持清晰平整。

## 特性

- 首页文章网格与真实文章封面
- 归档、标签、分类、友链和独立页面适配
- 亮色与暗色模式
- 移动端抽屉导航
- 置顶文章标记
- 键盘焦点、减少动态效果和长内容溢出处理

## 使用

在后台的主题管理中预览或启用 `Clay 黏土`。
