# Butterfly for Simple PHP Blog

移植自 [Typecho-Butterfly 1.8.1](https://github.com/wehaox/Typecho-Butterfly)，原始设计来自 [Hexo Butterfly](https://github.com/jerryc127/hexo-theme-butterfly)。本主题使用 Simple PHP Blog 的主题接口，无需安装 Typecho。

## 使用

在后台「主题管理」中找到 **Butterfly**，可先预览，再启用。新增主题不会自动更改站点当前使用的主题。

站点名称、副标题、描述、页脚、备案号和 favicon 沿用「站点设置」；侧栏资料读取第一个用户的昵称、头像、签名和 GitHub 地址，头像未设置时使用站点 `logo.png`。独立页面自动加入导航，分类、标签、友链和文章统计使用现有数据。

## 移植内容

- 图片页头、蓝色主色、交错封面的文章列表、响应式双栏布局。
- 首页分页、归档时间线、分类与标签列表、友链、独立页面和错误页面。
- 站内文章搜索，支持标题、摘要、正文和分页，仅检索已经公开发布的文章。搜索使用 `bf_q` 参数，不依赖额外插件。
- 跟随系统明暗模式，可手动切换并记住选择；侧栏显示偏好也会保留。
- 自动文章目录、阅读进度、阅读模式、返回顶部、代码复制/折叠/换行、图片放大。
- 原生 Markdown 与媒体嵌入、文章浏览量、点赞、评论、回复、审核反馈和防垃圾校验。
- 保留标准主题 action/filter 钩子、语言插件接口及自定义 head 代码。
- 禁用 JavaScript 时文章、导航、分页、搜索和评论表单仍然可用。

## 已选默认值

| 原主题选项 | 移植默认值 |
| --- | --- |
| 首页顶图 | 原包内 `img/image.png`，本地保存为 `assets/hero.png` |
| 文章封面 | 正文第一张 Markdown/HTML 图片；缺失或加载失败时使用原包默认封面 `assets/default-cover.jpg` |
| 首页顶图高度 | `100vh`，与原版 `full_page` 样式一致 |
| 配色、封面位置 | 原版蓝色配色、左右交错，手机端封面在上 |
| 字体、图标 | 系统字体、本地 Remix Icon，不请求字体 CDN |
| 侧栏公告 | 站点描述；未设置时隐藏 |
| 访问统计 | 公开文章数及原生文章浏览量，运行天数从首篇公开文章算起 |
| 评论系统 | 本项目原生评论；不加载 Typecho、第三方评论或验证码脚本 |
| Pjax、简繁转换 | 关闭，使用正常路由和现有语言插件 |
| 特效、天气、在线人数、热搜、Live2D、打赏、广告 | 默认关闭，不接入额外服务 |

主题没有引入单独的 Typecho 设置后台。需要替换固定图片时，可替换上述资源文件；其余默认样式位于 `style.css`。搜索使用 SQLite LIKE，中文可搜索，英文使用 SQLite 自带大小写规则。
