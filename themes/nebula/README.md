# Nebula 星云

深空 + 极光 · 玻璃拟态 · 暗色优先的 Simple PHP Blog 主题。

## 特性

- 星空粒子背景（Canvas，带鼠标视差与连线，遵循 `prefers-reduced-motion`）
- 三团极光光晕缓慢漂移
- 亮 / 暗主题切换，偏好保存在 `localStorage`（键名 `nebula-theme`）
- 吸顶玻璃导航，移动端汉堡菜单
- 首页：统计行（文章 / 标签 / 友链 / 运行天数）+ 渐变封面文章卡片网格 + 数字分页
  - 文章正文里的第一张图片会自动作为卡片封面，没有图片时使用 6 种渐变封面轮换
- 归档：渐变时间轴，按年份分组并显示每年篇数
- 标签：星云标签云，字号按文章数量分 5 级
- 标签页 / 分类页：时间轴式文章列表
- 友链：玻璃卡片网格，头像悬停旋转，无图标时显示首字母
- 文章页：完整的 Markdown 排版样式与玻璃拟态评论区
- 滚动渐入动画（无 JS 时内容依然可见）

## 安装

将 `nebula` 目录放入 `themes/`，然后进入「后台 → 站点设置 → 前台主题」选择 **Nebula 星云** 启用。

## 文件结构

- `theme.json` — 主题清单
- `layout.php` — 接管前台整体布局（星空背景、导航、页脚、回到顶部）
- `functions.php` — 通过 `content` filter 重渲染首页 / 归档 / 标签 / 分类 / 友链
- `style.css` — 全部样式（设计令牌见文件头部 `:root` 变量，可自行调整配色）
- `script.js` — 星空粒子、主题切换、移动端菜单、滚动渐入、回到顶部
