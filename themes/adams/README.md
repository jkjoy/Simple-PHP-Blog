# Adams for Simple PHP Blog

基于 [Tokinx/Adams](https://github.com/Tokinx/Adams) 1:1 移植的 Simple PHP Blog 主题。主题直接沿用上游 `style.css` 与 StrawberryIcon 图标字体，只为当前博客的内容和评论 DOM 追加必要兼容规则。

## 已适配

- 首页摘要列表与分页
- 文章、独立页面、上一篇/下一篇和评论
- 归档、标签、标签文章、分类文章和友情链接
- 固定信息栏、图片灯箱、分享、回到顶部
- 原版侧边搜索工具与站内文章搜索
- 默认、护眼、夜间配色以及 Serif / Sans 字体切换
- 移动端布局和 `prefers-reduced-motion`

原主题是 WordPress 主题，本目录中的 PHP 已依据 Simple PHP Blog 的主题钩子和数据接口重新实现，不依赖 WordPress 或 jQuery。

## 安装

进入“后台 -> 主题管理”，预览或启用 **Adams**。
